# GuessIO — Development Todo

Last updated: 2026-06-17 — reflects current Node/TypeScript game-server (not legacy C++).

---

## ✅ Done

### Core game
- Round lifecycle: start, timer, guess, end (`game-server/src/room.ts`)
- Server-side round timer auto-ends rounds
- Theme-based word fetch from FastAPI when streamer starts a round (`frontend/src/game/game.js`)
- Drawing canvas with stroke sync and replay
- **Drawing persists on page refresh** (disconnect no longer wipes room/strokes)
- Player list with case-insensitive dedup
- Gartic-style phases: word choosing → countdown → drawing (`game/phases.js`)
- Multi-round sessions (configurable round count via URL)
- Undo last stroke (no eraser yet)
- Session score display on round end (in-memory; not saved to DB)

### WebSocket (`game-server/`)
- JSON protocol: join, draw, clear, undo, start_round, get_state, etc.
- Multi-room `RoomManager`
- State restore on reconnect (`get_state` + stroke history)
- Client ping/pong keepalive
- WebSocket reconnect on abnormal close (`frontend/src/game/ws.js`)
- Guesses blocked over WebSocket (chat only)

### Twitch
- Bot spawn/stop per channel (`TwitchBotManager` + `/spawn_bot`)
- Chat commands: `join`, `!join`, `!guess` (plain-chat guesses disabled)
- Join is silent in chat — players show on streamer UI only
- Room ↔ channel mapping on spawn + streamer WS join
- Active room lookup by Twitch channel (`/api/rooms/active`)
- Only **joined** players can guess; streamer blocked from guessing in own chat
- Wrong guesses **not** broadcast to website (correct guesses only in feed)
- Chat announcements: round start, winner, timeout, round skipped
- Global chat rate limiter (~18 msgs / 30s) so bot won't get muted at scale
- Mod/broadcaster commands: `!skip`, `!endround`
- Twitch Helix stream-status API + live indicator on game page

### Backend
- FastAPI: auth, users, words, rooms, scores API
- Twitch OAuth login (session bug fixed)
- PostgreSQL + Alembic
- `twitch_channel` / `twitch_channel_id` on rooms (migration script)
- `/health` endpoint

### Frontend
- Landing page + streamer lobby (`index.html`, `game/lobby.js`)
- Theme selection, streamer game page (`game.html`)
- Shared stream layout CSS — lobby + game sidebars align for OBS camera slot
- `VITE_API_BASE_URL` for backend (`config.js`)
- Docker Compose (frontend, backend, game-server, postgres)

### Cleanup
- Removed dead gRPC / C++ code and updated README
